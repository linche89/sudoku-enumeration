## 2. 可行性数据(为什么墙在那里)

- **3×4 花了 107 天 / 2568 CPU·时**(2006);2022 年改进后仍需 1035 CPU·时。其"满带等价类(gangster)"= **144,578** 个(对比 9×9 的 **44**)。
- 9×9 快速法 ≈ **0.03 s**(kjellfp 2006);本仓库组合引擎 ≈ 0.9 s。
- 社区带计数复杂度:**4×C 为 $O(C^5)$,5×C 为 $O(C^{21})$,6×C 约 $O(C^{49}\log C)$**(PatmaxDaddy)。
- 2-盒 subband 等价类数(canonical):4×4=28,4×5=53,5×3=89,5×4=618,5×5=3087。

**暴力签名法的天花板(本仓库引擎)**:经转置数 C×2(2 条带,$N=\sum_\sigma B(\sigma)B(\bar\sigma)$),每盒签名 $\binom{2C}{C}$、整带 $\binom{2C}{C}^C$:

| 2×C | $\binom{2C}{C}^C$ | 暴力可行? |
|:--|--:|:--|
| 2×3 | 8.0×10³ | ✅ |
| 2×4 | 2.4×10⁷ | ✅ |
| 2×5 | 1.0×10¹² | ⚠️ 需对称归并 |
| 2×6 | 6.2×10¹⁷ | ❌ |
| 2×7 | 6.3×10²⁴ | ❌ |

## 3. go / no-go 结论

- **no-go**:3×5、4×4、4×5、5×5——算力/方法双重劝退(3×4 已是 107 天量级)。
- **no-go(以暴力法)**:2×6、2×7——暴力签名空间爆炸;够到它需复刻 Pettersen 的多项式带计数法(大工程、非新方法)。
- **go(复现+验证,非刷新)**:**搭通用 2×C 引擎,独立复现 2×3 / 2×4(/2×5)**——验证方法可推广、亲手定位墙。
- **若真要"新值"**:唯一现实路径是复刻 KSP/PatmaxDaddy 多项式算法去攻 2×6/2×7,或独立验证 Pettersen 的 2×6(~3.83×10⁴⁹)并提交 OEIS A291187——都属大工程,胜算与算力均不确定。

## 4. 相关开放问题(更大的母题,供长线参考)

- $L(12)$(12 阶拉丁方精确数)仍未知;OEIS A002860 只到 $n=11$。
- 渐近(Berend 2018):$S_n = n^{2n^4}e^{-3n^4+o(n^4)}$,核心是 permanent 上界(Brégman–Minc),紧性直觉与 Kilfoil 启发式同源。
- permanent 的随机近似(Jerrum–Sinclair–Vigoda FPRAS)理论上可用于拉丁矩形/数独的**近似**计数——这是真正没有天花板的方向。
- 变体已做:3D Sudo-cube = 14,515,200(Khovanova&Zhao 2018)。
