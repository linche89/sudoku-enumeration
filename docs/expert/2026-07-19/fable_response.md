核心结论先说：

信息保留悖论的三个真正出口是：(a) 不用"状态"携带 identity，改用闭式/回归结构；(b) 不用"配对状态"携带 identity，改用单拷贝空间上的矩表示（把平方线性化为 PSD 矩阵演化）；(c) 不用"精确状态"携带 identity，改用带符号松弛让 identity 由容斥符号隐式携带。 已被否决的所有路线（低秩截断、子集 DP、F4 查表、连通性算子）全都试图在"逐状态记录"的范式内压缩，而近单射性证明恰恰说明这个范式内没有压缩空间。以下提案全部跳出该范式。

---
P1（最便宜、最快出结论）：F(Q) 的结构回归与可乘性检验

动机：Pettersen 在 2006 年的硬件上完成了 63,199 类的加权平方和，而当前引擎单类要 700–1600 秒。差距约 100–1000 倍，这强烈暗示历史方法不是逐类 frontier DP，而是每类的代数求值——例如 F(Q) 沿 Q 的圈结构可乘、或由圈型不变量决定。

提案：纯离线回归，不写新引擎。项目手里有完美的数据集：C=4 全部类、C=5 全部 355 个 (orbit, multiplicity, F) 三元组，外加两个 C=6 保留值 F6(G1)、F6(G2) 作为天然 held-out 检验。测试：

1. 分量可乘性：若 Q 有不连通分量 Q₁⊔Q₂，是否 F(Q)=F(Q₁)·F(Q₂)（或差一个可控的组合因子）；
2. 圈型决定性：F 是否是 Q 的圈长重数向量的函数（先查 C=5 中圈型相同的类是否 F 相同——一次 sort 就能判定）；
3. 若 2 成立，拟合 F 关于圈长的乘积/转移公式（沿每个圈跑一个小转移矩阵），用 G1/G2 盲测。

若命中：N(6) 变成圈型上的生成函数计算（exponential formula），整个瓶颈消失；这同时几乎肯定复原了历史算法。若不命中：几小时成本，得到一个干净的否定记录，并且"圈型相同但 F 不同"的反例对 P6 的下界论证直接有用。这是所有提案中性价比最高的一条，建议最先做。

P2（主攻方向，回应请求 1）：矩矩阵 / Kraus 分解式的平方演化

这是我认为真正有数学新意的路线。讨论稿的算子形式本身就是一个 completely-positive 映射：

N = outᵀ · V_C · out,   V_0 = in·inᵀ,   V_{k+1} = Φ_k(V_k) = Σ_{|A|=C} M_{A,k} V_k M_{A,k}ᵀ.

关键换位：不要把配对 frontier 当作"状态→系数"的稀疏记录集合，而把它当作单拷贝空间 W_k 上的一个 PSD 矩阵 V_k，并且始终以分解形式 V_k = L_k L_kᵀ 存储。这在数学上是恒等式（gate i、ii 自动满足：V_k 的每个元素就是配对 frontier 系数），但计算形态完全不同：

- 初始秩为 1，每过一个 band 秩最多乘以割数（C=6 时 924），且永远有 rank(V_k) ≤ dim W_k（单拷贝维数）。近单射悖论被绕开：我们从不给"配对状态"发记录——存的是 d×r 个数，不是 #配对状态 条带 canonicalization 的哈希记录。
- 更新：L̃ = [M_{A₁}L | M_{A₂}L | …]（列拼接，#cuts·r 列），然后模素数精确秩压缩（2–3 个 64 位素数 + CRT + Freivalds 抽检）压回 r' = rank。应用成本 ≈ Σ_A (单拷贝转移支撑)·r，而配对支撑 ≈ Σ_A (单拷贝支撑)²——这正是请求 1 要的"不枚举转移支撑的快速精确应用"：结构性的平方根级改善。
- meet-in-the-middle：从两端各演化 3 个 band 到中点，N = ‖L_fwdᵀ·L_bwd‖²_F 型收缩，深度减半、前两层秩被 924、924² 硬性封顶。
- 对称性：V_k 自动 G-等变（in 是不变量，Σ_A 与 G 交换），所以可以在单拷贝轨道基上存 L，用现成的 multiset_q 规范化转移逐列应用 M_A（按割轨道加稳定子权重）。C=3/C=4 门：逐项复现保留的显式 K̄ 矩阵和端点值。
- 关键点：rank≥1024 的证书不否决此路线。那是对算子秩的下界；这里的开销由"状态矩阵"的秩 r_k 决定，且即便 r=d（最坏情形），成本也从"d² 条稀疏规范化记录"变成"d×d 的稠密模素数线性代数"——无逐记录 canonicalization、无哈希、可用 BLAS 级核。

判定门（预先声明）：① 用现有代码枚举单拷贝 C=5 grade-2/3 轨道数 d_single（目前项目只有配对数 38,801；若 d_single ~ 数百，则 38,801 ≈ d² 的账就对上了）；② 精确计算 C=5 的 r_2（复用 band_kernel_rank 的模素数消元设施）；③ 有界枚举 C=6 中层的 d_single，给出先验成本公式 #cuts·d·r·s。若 r_2(C=5) ≈ d_single 且 d_single(C=6) ≥ 10⁷，此路死，得到干净数字；若 r ≪ d 或 d(C=6) ~ 10⁴–10⁵，此路活。

P3（便宜、可能解锁 P2 与经典 DP）：交换子代数 / 相干闭包发现

"3+3 表示论通道"被否决的是截断；但没人测过 K̄ 的交换子代数维数。若 Comm(K̄) 严格大于对称群强制的部分，就存在隐藏守恒量 → 状态空间分解为扇区 → 经典 DP 和 P2 的每个块都变小。

做法：C=3（3×3）、C=4（141×141）矩阵已保留，解线性方程 XK=KX 是平凡计算；C=5 在采样列上测试候选守恒量、或对支撑模式做 Weisfeiler–Leman 相干闭包。一天工作量，输出要么是"无隐藏结构"的封闭记录，要么是新的扇区分解。

P4（回应请求 1 的第二机制，直接砍实测算术量）：带内符号松弛（升级版 B2/E3）

STATUS 里没有任何路线用过容斥/带符号松弛——这是全项目未开垦的机制。已排期的 B2/E3 融合列 frontier 的已知风险是带内部分状态近单射；解法：带内不枚举双射，改用 Ryser/Glynn 容斥——每行的双射约束松弛为独立选择减去符号项，带内 frontier 只需逐列线性形式/计数（直方图），symbol-到-column 的 identity 由 2^C 个符号项隐式携带，带内从不物化。跨 band 的列-符号集合状态不变，所以这不是全局崩塌，而是把每 (状态, 割) 的转移应用成本从 ~(C!)² 级枚举降到 2^C·poly(C)。对照实测：G2 重扫描做了 3.9×10¹¹ 次局部 assignment——砍 10–50 倍就把"63,199 类暴力独立验证"从 CPU-年级拉进多核数天级。即使 P1/P2 都失败，P4 单独就能把独立验证变成可行的工程。带符号大数用 mod-p + CRT 控制。门：逐项复现 C=3/C=4 转移矩阵，实测 C=5 每源操作数。

P5（结构注记，喂给 P2/P4）：圈因子 2^{#components} 的匹配对展开

joint-histogram 的连通性状态（live path endpoints 配对）存在的唯一理由是算 2^{#cycles}。恒等式：2-正则二部多重图的 2^{#components} = 它分解为两个完美匹配的有序方式数。所以圈因子可以换成"多选一个匹配分解"，即回到显式共享割形式（C=6 只有 924 个割，枚举是免费的）——路径配对状态整体删除。这使 joint-histogram 路线也能套 P2 的矩形式与 P4 的容斥；同时把每带耦合暴露为 α=2 permanent（per₂），可接入已知的 permanent 求值技术。

关于请求 2（全局 4+2 Gram），一个已推演的负面结果

我推演过最自然的构造并建议记录它，免得反复重新发现：定义 G = Pᵀ W P（P 为 4+2 gluing 关联算子），想用 N = uᵀGu 且 G 的元素由 (x,y,x′,y′) 的 contingency 叠合闭式给出、从而绕开 Q 枚举。它退化：同一位置带分割下，Q 的前 4 带子骨架决定 [x]，故 G 按 ([x],[y]) 块对角、无混合，退回原求和。改用两份拷贝不同的带分割（12|3456 × 1234|56）可产生混合，但接口恰好又是 2+2 gluing 的 contingency 数据——回到 1.76B 双陪集清单。结论：任何按"带位置分割"因子化的 Gram 构造都撞同一堵墙；一个不退化的请求-2 构造必须不经过位置分割因子化。这实际上把请求 2 收窄成了 P2（矩收缩正是"不按位置逐类、而按张量结构"的全局收缩）。

P6（回应请求 3）：把下界做成定理，划定逃逸面

把已有的 1,024 秩证书升级为通信复杂度陈述：Alice 持前 k 带、Bob 持后缀，精确计算 Σ wF² 的任何双线性 frontier 方案维数 ≥ rank(历史×未来通信矩阵)。用现成 sketch 设施把 C=5 下界从 1,024 推到 4,096/16,384（或对结构子矩阵做 LDU 证书逼近满秩）。价值不在数字本身，而在定理形状：它只封锁"更小维数的线性 frontier"，明确列出三个不受封锁的逃逸面——P1（每类闭式）、P2（满维但分解存储）、P4（维数不是成本的带符号松弛）。这把讨论稿的"impossibility would also be valuable"变成一份指路文件而非墓志铭。

P0（所有路线共同的先决测量）

没有任何人知道 C=6 中层的两个基数：单拷贝轨道数 d_single 和配对轨道数。它们决定每条路线的先验成本。用现有 multiset_q/mp_q 设施做有界枚举（哪怕只到 grade-2/3 的抽样外推），是一次性投资。
